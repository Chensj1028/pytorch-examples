# MNIST 手写数字识别入门

本文中的运行命令均在仓库根目录执行。

本地 Python 环境位于 `.venv`，使用 CPU 版 PyTorch。

## 开始训练

在 PowerShell 中运行：

```powershell
# 先在终端进入克隆后的 pytorch-examples 目录
.\run_mnist.cmd
```

默认训练 1 轮并测试，模型保存到 `mnist/mnist_cnn.pt`。首次运行会下载 MNIST 数据集到仓库的 `data` 目录；以后可以直接使用已下载的数据。

要训练更多轮，可以运行：

```powershell
.\run_mnist.cmd --epochs 3
```

每次训练都会重新初始化模型，保存时会覆盖上次的 `mnist/mnist_cnn.pt`。

## 阅读顺序

打开 `mnist/main.py`：先看 `Net`（网络结构），再看 `train`（训练）、`test`（评估），最后看 `main`（数据加载和整体流程）。

启动脚本自动使用独立环境，无需手动激活环境。它将 CPU 计算线程数设为 4，适合先学习和验证流程。

## 已验证的运行结果

2026-11-04，使用 Python 3.12.10、PyTorch 2.15.0+cpu、torchvision 0.29.2+cpu，在完整的 60,000 张训练图片上训练 1 轮。

- 测试集：10,000 张图片，识别正确 9,845 张，准确率 98.45%。
- 平均测试损失：0.0438。
- 模型：`mnist/mnist_cnn.pt`。
- 首次训练日志：`mnist/training.log`。
- 依赖检查：`pip check` 通过。

当前依赖版本保存在 `requirements-cpu-lock.txt`。需要重建环境时，在项目根目录运行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-cpu-lock.txt --index-url https://download.pytorch.org/whl/cpu
```
